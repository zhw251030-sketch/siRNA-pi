# 第10L步实施计划

设计见同目录 `2026-10-21-tool-maintenance-design.md`。

1. 实现与测试：维护作业 SQLite 存储、串行 worker、验证运行日志工厂、安全摘要、三个公共 API、候选面板及关闭接线。先写能失败的行为测试，再最小实现。由单一实施子代理负责，避免并行修改。
2. 独立复审：按设计检查状态、持久化、请求去重、验证权限和关闭；修复发现后重跑相关测试。
3. 服务器准备：确认 main 基线与空闲状态，保存旧数据哈希与容器清单，通过项目 runtime 中精确清单传输本轮文件。
4. 验证：本机完整测试；服务器完整测试；只重启项目网页进程；真实网页发起第10K候选验证一次，核对报告、执行次数、界面与旧数据保持；空闲重启核对恢复和不重跑。
5. 教学交付：编写 `docs/25-网页候选验证队列.md`、更新 README/学习路线/AGENTS 的最新进度，引用实际代码和原版职责；区别已实现与下一步。
6. 最终复审和同步：检查无密钥/真实私有日志进入 Git，main 提交推送，服务器 Git bundle 对齐并核验三处提交及干净状态。

工作台与运行证据放在已忽略的项目 `runtime/`，不另建工作树；这是遵循用户 main-only 和项目目录范围的适配。只读原版分析可与实施并行；生产代码由一位实施者修改。核心代理负责部署、真实验收和解释。
