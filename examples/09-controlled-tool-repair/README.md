# 一轮受控修订练习

`proposal.draft.json` 是人为设计的错误根候选，不是 Agent 自主发现的问题。它把数组的首尾值当作最小值和最大值：排序输入 `[-2,0,5]` 会成功，乱序 `[6,2,4]` 会暴露错误。

先让一个新的网页任务原样构建并提交草稿；只能把实际 finalize 产生的 `runtimeArtifact` 加进去，不能伪造。独立验证失败后，在候选详情点击一次“请求修订”，把完整源码、冻结合同和已核验失败报告送回该任务。修订仍需新的构建会话和真实新候选。原测试、期望、baseline 等合同保持，不能通过修改评分标准使自己通过。

新候选仍要显式独立验证，批准也需另行处理。当前每条绑定的修订链最多三代替代候选，不是三次模型请求或金额上限。本次演示只运行一轮根构建和一轮修订，不循环重试。这是流程教学；小样例和故意弱基线不构成自进化效果证据。
