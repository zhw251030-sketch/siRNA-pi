# 网页 Pi 构建练习

`proposal.draft.json` 是完整业务提案草稿，唯独缺少只能由实际打包取得的 `runtimeArtifact`。不要伪造镜像编号。网页上传草稿后，让 Pi 读取其 `script`，通过构建工具写入 `/opt/tool/main.mjs`，用标准输入 `{"input":{"values":[6,2,4]}}` 调试，再原样附上 finalize 返回的 artifact 提交。

期望调试结果为 `{"count":3,"min":2,"max":6,"range":4}`。`baseline` 故意保留“输入已经排序”的错误假设，供后续学习独立验证和正确率差异使用；不是成熟基线、性能提速证据或科研结论。本步只提交候选，不执行这些独立测试与基准，不批准上线。

六个构建工具在同一轮对话内使用。可以另外创建一个空会话并显式取消，学习主动回收；再创建一个空会话并结束本轮，观察host自动回收。完成的候选镜像和提案会保留。旧轮sessionId不能跨轮继续用。
